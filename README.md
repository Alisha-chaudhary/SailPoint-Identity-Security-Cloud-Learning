# SailPoint Identity Security Cloud Learning

A structured collection of self-written learning notes covering **SailPoint Identity Security Cloud (ISC)**, its core concepts, and identity security capabilities.

This repository is intended to serve as both a personal learning reference and a beginner-friendly resource for others exploring identity security and Identity and Access Management (IAM).

## About This Repository

This repository documents my learning journey through SailPoint University's **Introduction to Identity Security Cloud** course.

The notes will cover the platform's architecture, identity model, access modelling, access requests, access certifications, provisioning, and password management.

The goal is to understand not only what each capability does, but also how the concepts fit into the broader identity security lifecycle.

## What Is Identity Security Cloud?

**Identity Security Cloud (ISC)** is SailPoint's cloud-based identity security platform. It provides capabilities for managing and governing digital identities and their access to organisational resources.

Identity security focuses on ensuring that the right individuals have the appropriate access to the right resources, for the right reasons, and for the appropriate duration.

This involves activities such as:

- Understanding and managing digital identities.
- Modelling and governing access.
- Requesting and approving access.
- Reviewing access through certifications.
- Provisioning and managing access.
- Managing identity-related passwords.

> **Note:** Identity Security Cloud and IdentityIQ are separate SailPoint platforms. This repository focuses specifically on Identity Security Cloud. My IdentityIQ learning notes are maintained separately in the [SailPoint IdentityIQ Learning repository](https://github.com/Alisha-chaudhary/SailPoint-IdentityIQ-Learning).

## Course Overview

The introductory course provides an overview of Identity Security Cloud, its features, and its capabilities.

It is a self-paced eLearning course designed to establish foundational familiarity with the platform before progressing to more practical administration and configuration topics.

## Learning Approach

The notes will be developed progressively while working through the course.

The documentation aims to:

- Explain concepts in clear, beginner-friendly language.
- Organise related concepts into logical sections.
- Use comparison tables where they make distinctions easier to understand.
- Include workflow diagrams where they help explain processes.
- Add practical examples to connect concepts with real IAM scenarios.
- Distinguish course concepts from additional explanations and examples.

The material will be rewritten and organised into original learning notes rather than reproduced as course transcripts.
